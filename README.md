# Premium System Dashboard & Habit Tracker 🚀

## 📌 Project Overview

Premium System Dashboard & Habit Tracker is a Python desktop application built using Tkinter.
It helps users manage their daily schedules, reminders, and habits through an interactive dashboard.

The application provides a clean dashboard interface with calendar integration, reminder management, weekly agenda tracking, and habit streak monitoring.

## ✨ Features

- 📅 Interactive Calendar Dashboard
- 🔔 Create and manage reminders
- 📝 Delete reminder events
- 📆 Upcoming 7-day agenda view
- ✅ Daily habit tracker
- 🔥 Habit streak tracking
- 💾 Local data storage using JSON
- 🎨 Modern dark-themed user interface

## 🛠️ Technologies Used

- Python
- Tkinter (GUI Development)
- tkcalendar
- JSON
- File Handling
- Object-Oriented Programming
